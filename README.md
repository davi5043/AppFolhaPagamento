# 📱 App Folha de Pagamento

Aplicativo Android desenvolvido em Java para calcular o salário líquido de um funcionário, considerando descontos e benefícios.

## 🚀 Funcionalidades

- Entrada de dados:
  - Nome do funcionário
  - Salário bruto
- Seleção de tratamento (Sr. / Sra.)
- Cálculo automático de:
  - INSS
  - Imposto de Renda (IR)
  - Salário Família
  - Salário Líquido
- Exibição dos resultados na tela

## 🧮 Regras de Cálculo

- INSS: baseado no salário informado
- IR: descontado conforme faixa salarial
- Salário Família: aplicado conforme regras de renda
